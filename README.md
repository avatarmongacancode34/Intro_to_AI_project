# AI-Powered Adinkra Symbol Recognition and Cultural Heritage Preservation System 


## Project Description

Adinkra AI is an AI-powered image classification system designed to recognize and classify Ghanaian Adinkra symbols from images.

The system uses a Convolutional Neural Network (CNN) to learn visual patterns from Adinkra symbol images and predict the class of a given input image.
